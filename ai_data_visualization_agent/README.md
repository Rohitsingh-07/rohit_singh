A Streamlit application that acts as your personal **AI Data Visualization Expert**, powered by **local Ollama models**.  

Simply upload your dataset and ask questions in natural language - the agent analyzes your data, generates appropriate visualizations, runs Python code dynamically, and provides clear insights with charts and statistics.

This project demonstrates how to combine local LLMs with a secure code execution environment to build an intelligent, interactive analytics system.

---

## 🚀 Overview

This AI agent:

- Reads your uploaded dataset  
- Understands your natural language question  
- Generates Python analysis code  
- Executes it safely in a sandbox  
- Returns visualizations and insights  

All LLM inference runs through locally hosted Ollama models, enabling a flexible and privacy-friendly architecture.

---

## ✨ Features

### 🗣 Natural Language Data Analysis
- Ask questions in plain English
- Compare metrics across categories
- Analyze trends and distributions
- Perform statistical summaries
- Generate follow-up insights

---

### 📊 Intelligent Visualization Generation
- Automatic chart selection
- Bar charts, line plots, scatter plots, distributions
- Statistical comparisons
- Dynamic Matplotlib & Plotly rendering
- DataFrame previews and summaries

---

### 🧠 Local LLM Model Support (Ollama)

Supports locally hosted models such as:

- Meta-Llama 3.1 405B for complex analysis
- DeepSeek V3 for detailed insights
- Qwen 2.5 7B for quick analysis
- Meta-Llama 3.3 70B for advanced queries

Models can be switched depending on:
- Depth of reasoning required
- Dataset size
- Complexity of analysis

---

### 🔐 Secure Code Execution

- Python code generated by the model
- Executed inside an isolated sandbox environment
- Captures stdout, stderr, plots, and DataFrames
- Prevents unsafe execution in the main app

---

## 🧠 Tech Stack

- **LLM Runtime**: Local Ollama Models  
- **Frontend/UI**: Streamlit  
- **Data Handling**: Pandas  
- **Visualization**: Matplotlib / Plotly  
- **Secure Execution**: E2B Sandbox  
- **Language**: Python  

---

## 🏗 How It Works

1. User uploads a CSV dataset  
2. User enters a natural language query  
3. The LLM:
   - Understands the dataset path  
   - Generates Python analysis code  
4. Code runs in a sandbox environment  
5. Results (charts, tables, outputs) are rendered in Streamlit  

---
